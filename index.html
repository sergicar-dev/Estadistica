Empieza con tus datos

Tipo de análisis: poblacional. Las medidas de dispersión y los momentos se calculan sobre el conjunto completo ingresado; la varianza utiliza divisor N.

La detección automática interpreta una lista totalmente numérica como cuantitativa. Selecciona manualmente la naturaleza conceptual cuando los números sean códigos, o cuando una variable continua esté registrada con enteros.

Escribe todos los niveles observados separados por el símbolo >. Si los niveles son códigos numéricos (1, 2, 3…), se pueden ordenar automáticamente.

Pegar datos manualmente

Separa los valores con comas y usa punto decimal (ej.: 12, 15.5, 18, 20). Si usas coma decimal, separa los valores con punto y coma: 12,5; 15,2; 18,0.

Importar archivo CSV o Excel

Carga un archivo .csv, .xlsx o .xls. Usa una sola variable: un dato por fila en una columna, o una única fila con las observaciones separadas.

Para evitar mezclar variables, el archivo debe contener una sola columna de observaciones (o una sola fila con los datos). Si contiene varias columnas con datos, prepara una copia con únicamente la variable que vas a analizar.

Error

Revisa los datos ingresados.

Fórmulas y convenciones matemáticas

Las siguientes expresiones corresponden al análisis poblacional implementado. Los cuartiles se estiman mediante interpolación lineal de tipo 7 (posición p·(N−1)); otros programas pueden usar convenciones diferentes.

Media aritméticaμ = (Σ xᵢ) / N

Suma de las observaciones dividida entre el número total de datos.

Mediana y modaMe = valor central ordenadoMo = valor(es) con frecuencia máxima

Si N es par, la mediana es el promedio de los dos valores centrales; si todos los valores aparecen una vez, se informa amodal.

Cuartiles y rango intercuartílicor = p(N−1); Qₚ = interpolación en la posición rRIC = Q₃ − Q₁

Se usan p = 0,25; 0,50 y 0,75.

RangoR = máximo(x) − mínimo(x)
Varianza y desviación estándar poblacionalesσ² = Σ(xᵢ − μ)² / Nσ = √σ²

Se divide entre N porque se describe la población ingresada, no una muestra.

Coeficiente de variaciónCV = (σ / |μ|) × 100 %

Se considera no definido cuando μ = 0; su interpretación requiere una escala de razón con cero significativo.

Momentos centralesmₖ = Σ(xᵢ − μ)ᵏ / N, para k = 1, 2, 3, 4

Teóricamente m₁ = 0 y m₂ = σ².

Asimetría y curtosisγ₁ = m₃ / σ³β₂ = m₄ / σ⁴; exceso = β₂ − 3

La interfaz muestra β₂ (la referencia de la distribución normal es 3), no el exceso de curtosis.

Atípicos: criterio de TukeyLI = Q₁ − 1,5·RICLS = Q₃ + 1,5·RIC

Se señalan las observaciones estrictamente menores que LI o mayores que LS.

Datos agrupados: regla de Sturgesk ≈ 1 + 3,322·log₁₀(N)Amplitud = (máximo − mínimo) / k

El número de clases se redondea al entero más cercano; se agrupan variables cuantitativas con más de 10 valores distintos.
